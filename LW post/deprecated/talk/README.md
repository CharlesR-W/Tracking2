# Talk archive

This directory preserves the Tracking2 talk **as delivered**. Its HTML and PDF
exports use preliminary CNN depth-by-time and one-model ResNet pilot data that
predate the July 26 control battery.

Do not silently update these files to match the publication post, and do not use
their pilot figures as evidence for the post's current quantitative claims. The
canonical post evidence is the CNN-only manifest at
`../../../artifacts/lw_post/dashboard_manifest.json`; the measured appendix is
`../../free-body-diagrams-for-neural-networks.html`.
